## The question comes first.

I've always been the person who asks **where the number came from**.

That question is what pulled me into analytics.

I like the part of the work that happens before the polished dashboard: finding the source, understanding the process that produced the data, deciding what should be trusted, and figuring out what the number is actually supposed to change.

I work end to end — **data → SQL → modeling → analysis → BI → decision**.

And I have one rule for dashboards:

> **If the person using it still needs me to explain what they're looking at, I haven't finished the job.**

## How I work

**01 — Start with the decision**  
What does someone need to decide? Everything else follows from that.

**02 — Trace the number**  
Source → transformation → definition → metric. If I cannot explain the lineage, I don't trust the number yet.

**03 — Model before decorating**  
A good visual cannot rescue a weak data model.

**04 — Build for the user**  
A dashboard should reduce cognitive load, not add another layer of work.

**05 — Leave a trail**  
Queries, transformations and assumptions should be understandable and reproducible.

## Portfolio direction

I'm building my portfolio around problems that look like **real work**, not exercises designed only to demonstrate syntax.

### Sales Decision Intelligence
**Raw commercial data → trusted KPIs → decision-ready BI.**

Focus: sales performance, product mix, trends, targets and actionable segmentation.

### Supplier Performance Intelligence
**Operational records → supplier risk → management visibility.**

Focus: lead time, delivery reliability, price variation, quality signals and purchasing patterns.

### Operations Analytics
**Process data → bottleneck detection → improvement opportunities.**

Focus: throughput, delays, pending work, planned vs. actual and operational performance.

### Cohort & Retention Analysis
**Customer events → behavior over time → retention insight.**

Focus: cohorts, retention curves, segmentation and the difference between acquisition and durable value.

> Portfolio datasets are kept synthetic or anonymized whenever the original data is proprietary. Good analytics should never require publishing someone else's business data.
